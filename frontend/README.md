# AviaPlan Frontend

Next.js 15 App Router web client with authentic airline design, Takeoff animation, boarding pass card, and live audit log view.

## Setup & Run

1. **Install Dependencies**:
```bash
npm install
```

2. **Environment Variables**:
Create `.env.local`:
```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

3. **Run Dev Server**:
```bash
npm run dev
```
Open `http://localhost:3000` in browser.
